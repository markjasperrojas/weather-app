# Todo List

A To-Do List helps you organize, track, and complete tasks.

🔗 **Live Demo:** https://markjasperrojas.github.io/todo-list/

In this project, I practiced using ES6 modules, localStorage, and learned more about organizing code. Although my code is still a bit messy and needs refactoring and cleanup, it was a great learning experience. Due to my NC II training, I wasn't able to dedicate as much time to this project as I had hoped. As a result, the project is still missing some features that I originally planned to implement, leaving plenty of room for future improvements. This project was built from scratch as part of the [The Odin Project](https://www.theodinproject.com/) curriculum.
