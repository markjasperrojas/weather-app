# Weather App

This weather app is a simple website that shows basic current atmospheric conditions.

🔗 **Live Demo:** https://markjasperrojas.github.io/weather-app/

In this project, I implemented and practiced what I learned about asynchronous JavaScript and APIs, particularly Promises, `async`, and `await`. This project was built from scratch as part of [The Odin Project](https://www.theodinproject.com/) curriculum.
