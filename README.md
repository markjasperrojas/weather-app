# 🌤️ Weather App

A simple weather application that displays current weather conditions for any location using the Visual Crossing Weather API.

---

## 🛠️ Technologies

- JavaScript (ES6+)
- HTML & CSS
- Webpack
- Visual Crossing Weather API

---

## ✨ Features

- Search the current weather for any city or address.
- Temperature, feels like, humidity, and wind speed at a glance.
- Weather icon and description that change with the current conditions.
- °C / °F toggle that also switches wind speed between km/h and mph, and stays the same across searches.
- Friendly error messages for unknown locations and network problems.
- Responsive layout for desktop and mobile.

---

## 🧩 Process & Learnings

I built this project from scratch as part of [The Odin Project](https://www.theodinproject.com/) curriculum. It gave me hands-on practice with asynchronous JavaScript and APIs, particularly Promises, `async`, and `await`, as well as fetching data from a third-party API, handling errors, and turning the response into a clean user interface.

## 🔧 Future Improvements

- **API security:** Move API requests behind a serverless function to protect the API key.
- **Loading states:** Add visual feedback while fetching weather data.
- **Weather forecasts:** Include hourly and multi-day forecasts.
- **Weather icons:** Add more accurate icons for snow, fog, wind, and nighttime conditions.
- **Geolocation:** Allow users to get weather information based on their current location.
- **Persistent preferences:** Remember the selected temperature unit after page reloads.

## 🚀 Running the Project

### Prerequisites

- [Node.js](https://nodejs.org/) 20.19 or newer
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/markjasperrojas/weather-app.git

# Navigate to the project folder
cd weather-app

# Install dependencies
npm install

# Start the development server
npm run dev
```
